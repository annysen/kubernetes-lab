# Kubernetes Lab

A hands-on learning repository for Kubernetes.

This repository contains practical exercises, YAML manifests,
command examples, configuration guides, and troubleshooting
notes covering different Kubernetes concepts.

## Objectives

- Learn Kubernetes through hands-on practice.
- Understand Kubernetes resources and architecture.
- Practice configuring and managing workloads.
- Explore networking, storage, security, and scheduling.
- Document common problems and their solutions.

## Topics

- Pods
- Deployments and ReplicaSets
- Namespaces
- Services
- DaemonSets
- Multi-container Pods
- Labels and Selectors
- Scheduling
- Resource Management
- ConfigMaps and Secrets
- RBAC
- Storage
- Network Policies
- Ingress
- Autoscaling
- Cluster Maintenance
- Backup and Restore

## Lab Environment

The examples in this repository are developed and tested
in a personal Kubernetes lab.

The lab environment may change as the project evolves.

Specific environment details and prerequisites will be
documented where relevant.

## Learning Approach

Each topic includes practical examples, commands, YAML
manifests where applicable, verification steps, and
troubleshooting notes.
