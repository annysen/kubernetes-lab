# Kubernetes Pods

## How to Create a Pod

### Step 1: Generate the Pod YAML

Generate the Pod YAML file without creating the Pod.

```bash
kubectl run nginx-pod --image=nginx --dry-run=client -o yaml > basic-pod.yaml
```

**Explanation:**
- `kubectl run`: Generates a Pod definition.
- `nginx-pod`: The name of the Pod.
- `--image=nginx`: Specifies the NGINX container image.
- `--dry-run=client`: Generates the YAML without creating the Pod.
- `-o yaml`: Outputs the definition in YAML format.
- `> basic-pod.yaml`: Saves the YAML output to a file.

### Step 2: Understand the Pod YAML

The generated `basic-pod.yaml` file will look like this:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx-pod
  labels:
    app: nginx
spec:
  containers:
    - name: nginx
      image: nginx:stable
      ports:
        - containerPort: 80
```

**Explanation:**

- `apiVersion: v1`: Specifies the Kubernetes API version.
- `kind: Pod`: Defines the resource type as a Pod.
- `metadata.name`: Specifies the Pod name.
- `metadata.labels`: Assigns labels to the Pod.
- `spec.containers`: Defines the containers inside the Pod.
- `name: nginx`: Specifies the container name.
- `image: nginx:stable`: Specifies the NGINX container image.
- `containerPort: 80`: Documents the port used by the container.

**Note:** The exact YAML generated by the command may differ depending on the command options and Kubernetes version.

### Step 3: Create the Pod

Apply the YAML file to create the Pod.

```bash
kubectl apply -f basic-pod.yaml
```

Expected output:

```text
pod/nginx-pod created
```

### Step 4: Check the Pod Status

Check whether the Pod is running.

```bash
kubectl get pods
```

Example output:

```text
NAME        READY   STATUS    RESTARTS   AGE
nginx-pod   1/1     Running   0          10s
```

**Explanation:**
- `READY`: Shows how many containers are ready.
- `STATUS`: Shows the current Pod status.
- `RESTARTS`: Shows how many times the container has restarted.
- `AGE`: Shows how long the Pod has existed.

### Step 5: Get Detailed Pod Information

Use the following command to see detailed information about the Pod.

```bash
kubectl describe pod nginx-pod
```

This command displays information about the Pod, its container, assigned node, IP address, and events.

### Step 6: Delete the Pod

After completing the exercise, delete the Pod using:

```bash
kubectl delete -f basic-pod.yaml
```

Verify that the Pod has been deleted:

```bash
kubectl get pods
```

## Key Takeaways

- A Pod is the smallest deployable unit in Kubernetes.
- `kubectl run --dry-run=client -o yaml` generates a YAML definition without creating the Pod.
- `kubectl apply -f` creates or updates a resource using a YAML file.
- `kubectl get pods` displays Pod status.
- `kubectl describe pod` provides detailed information about a Pod.
- `kubectl delete -f` deletes the resource defined in a YAML file.
